JavaScript Object Notation

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato utilizado para representar e intercambiar información.

Es muy utilizado para comunicar aplicaciones web con servidores y APIs.

Estructura de JSON

JSON utiliza pares de clave y valor. 



{
    "producto": "Laptop",
    "precio": 899,
    "categoria": "Computadoras",
    "disponible": true
}

Arreglos



{
    "productos": [
        "Laptop",
        "Smartphone",
        "Audifonos"
    ]
}

Objeto JavaScript vs JSON

Objeto JavaScript



const producto = {

    nombre: "Laptop",

    precio: 899

};

JSON



{
    "nombre": "Laptop",
    "precio": 899
}

¿Cómo utilizan JSON las páginas web?

Una aplicación puede solicitar información a un servidor. El servidor puede enviar los datos en formato JSON y JavaScript puede recibirlos y mostrarlos en la página.
