¿Qué es JavaScript?

El lenguaje que agrega interacción y comportamiento a las páginas web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas.

Permite responder a las acciones del usuario, modificar contenido, mostrar mensajes, realizar cálculos y crear diferentes efectos.

HTML, CSS y JavaScript

Tecnología Función
HTML Define la estructura de la página.
CSS Define el diseño y apariencia.
JavaScript Agrega comportamiento e interacción.

Conceptos básicos

Variables

Permiten almacenar información.

Funciones

Son bloques de código que realizan una determinada tarea.

Eventos

Son acciones que ocurren en una página, como hacer clic o pasar el mouse.
