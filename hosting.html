Hosting y Dominios

¿Cómo se pone una página web en Internet?

¿Qué es Web Hosting?

El Web Hosting es un servicio que proporciona espacio en un servidor para almacenar los archivos de una página web.

Hosting compartido

Varios sitios web comparten los recursos de un mismo servidor.

VPS

Es un servidor virtual que proporciona recursos asignados.

Hosting en la nube

Utiliza recursos distribuidos entre diferentes servidores.

¿Qué es Vercel?

Vercel es una plataforma que permite desplegar sitios web y aplicaciones. Puede conectarse con GitHub para publicar proyectos.

¿Qué es un dominio?

Un dominio es el nombre que utilizamos para acceder a un sitio web. 



www.techzone.com
  • Subdominio: www
  • Nombre: techzone
  • TLD: .com

Propagación DNS

DNS permite relacionar un dominio con la dirección donde se encuentra un sitio web.
