¿Qué es jQuery?

jQuery es una biblioteca de JavaScript creada para facilitar tareas comunes en el desarrollo de páginas web.

¿Por qué nació jQuery?

jQuery nació para simplificar tareas como seleccionar elementos HTML, trabajar con eventos, crear animaciones y manipular el contenido de las páginas.

Sintaxis básica



$("#boton").click(function(){

    alert("Hola desde jQuery");

});

El símbolo $ se utiliza normalmente para seleccionar elementos y trabajar con ellos.

Ventajas y desventajas

Ventajas

  • Sintaxis sencilla.
  • Facilita algunos efectos.
  • Simplifica algunos eventos.

Desventajas

  • Necesita una biblioteca externa.
  • Muchas tareas actualmente pueden realizarse con JavaScript moderno.
